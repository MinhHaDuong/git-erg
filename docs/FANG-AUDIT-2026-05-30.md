# Fang Audit — `erg` Go test harness

_Mutation-testing audit: each test was probed by breaking the code it covers and checking whether the test goes red. Generated by the `fang-audit-erg` fan-out workflow (19 files · 31 agents · ~29 min · 1.3M tokens). **No source or test files were changed in the repo** — every mutation lived and died in a throwaway git worktree._

## Canary (validity gate)

✅ **PASS** — both guard tests caught their primary canary mutation, so the mutation harness itself works and the findings below are trustworthy:
- `scaling_test.go` → **caught** — erg.go loadErgs (~line 689): wrap the per-ticket assignment loop in a nested loop that re-parses the entire corpus for every ticket (for i { for j { parseErg(pairs[j].t.Path) } }), reintroducing O(N^2) total parse work and O(N^2) allocated bytes.
